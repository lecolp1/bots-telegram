# Telegram-бот: Заказ услуг и Прайс

Простой и удобный Telegram-бот на фреймворке **aiogram 3**, разработанный для просмотра актуального прайс-листа и отправки заявок клиентов администратору. В боте реализовано удобное меню и пошаговая форма (FSM) для безопасного сбора контактных данных.

---

## 🛠 Технологии
* **Python 3.10+**
* **aiogram 3.x** (для работы с Telegram API)
* **python-dotenv** (для безопасного хранения секретных ключей)

---

## 🚀 Функционал
* 💰 **Прайс-лист** — просмотр актуальных цен на услуги прямо в чате.
* 📞 **Контакты** — информация о расположении и способах связи.
* 📝 **Оставить заявку** — интерактивная форма заказа, которая запрашивает имя и телефон пользователя, после чего мгновенно пересылает эти данные администратору в личные сообщения.

---

## 💻 Установка и запуск проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd имя_репозитория
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения (Важно для безопасности!)
Создайте в корне проекта файл `.env` и впишите туда ваш личный токен и ID администратора:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_telegram_id_here
```
*(Файл `.env` автоматически игнорируется системой Git и не попадет в открытый доступ)*

### 5. Запуск бота
```bash
python main.py
```

* `main.py` — основной код бота и обработчики команд.
